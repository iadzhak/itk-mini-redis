# mini_redis

In-memory key-value хранилище с TTL и LRU-eviction, доступ через gRPC.

## Возможности

- **Put / Get / Delete** — основные операции с ключами
- **TTL** — опциональный срок жизни ключа (`ttl_seconds = 0` — без истечения)
- **LRU eviction** — автоматическое удаление наименее используемых записей при заполнении
- **List по префиксу** — возврат всех ключей с данным префиксом, истёкшие исключаются
- **Потокобезопасность** — все операции хранения защищены lock'ом
- **Логирование** — логирование каждого запроса с ID

## Установка

Требуется **Python ≥ 3.12** и [uv](https://github.com/astral-sh/uv).

```bash
uv sync
```

## Конфигурация

Настройки загружаются из `.env` (или переменных окружения):

| Переменная     | Значение по умолчанию | Описание                        |
|----------------|-----------------------|---------------------------------|
| `PORT`         | `50051`               | Порт gRPC-сервера               |
| `MAX_WORKERS`  | `0`                   | Макс. кол-во потоков (0 = авто) |
| `LRU_EVICTION` | `10`                  | Макс. кол-во записей в кэше     |
| `LOG_LEVEL`    | `INFO`                | Уровень логирования             |

## Запуск

### Локальная разработка

```bash
uv run dev
```
